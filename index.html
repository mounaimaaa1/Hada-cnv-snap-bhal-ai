# API Reference ## MediatorApp Main application class for managing social media posting engines. ### Constructor ```javascript new MediatorApp(settingsPath = null) ``` **Parameters:** - `settingsPath` (string, optional) - Path to settings.json file. If not provided, uses default path. ### Methods #### `initialize()` Initialize the application and create engines for enabled platforms. ```javascript await app.initialize(); ``` **Returns:** `Promise` --- #### `start()` Start the application, connect to all platforms, and start the scheduler if enabled. ```javascript await app.start(); ``` **Returns:** `Promise` --- #### `post(platforms, content)` Post content to specified platforms. ```javascript const results = await app.post(['facebook', 'twitter'], { text: 'Your post content', mediaUrl: 'https://example.com/image.jpg' }); ``` **Parameters:** - `platforms` (Array) - Array of platform names to post to - `content` (Object) - Content object - `content.text` (string) - Text content of the post - `content.mediaUrl` (string, optional) - URL of media to attach **Returns:** `Promise>` - Array of result objects **Result Object Structure:** ```javascript { platform: 'facebook', success: true, timestamp: '2024-01-01T12:00:00.000Z', response: { postId: '123456789', message: 'Post published successfully' }, error: null } ``` --- #### `getSchedulerStatus()` Get the status of all scheduled jobs. ```javascript const status = app.getSchedulerStatus(); ``` **Returns:** `Array
